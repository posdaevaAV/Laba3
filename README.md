#  Калькулятор с историей операций

**Лабораторная работа №3**  
**Дисциплина:** Командная разработка на GitHub

## Описание

Консольный калькулятор с расширенным функционалом:
- Выполнение базовых арифметических операций
- Сохранение истории всех вычислений
- Модульная архитектура с классами
- Покрытие модульными тестами

## Функционал

### Основные операции:
- ➕ Сложение
- ➖ Вычитание
- ✖️ Умножение
- ➗ Деление (с защитой от деления на ноль)

### Дополнительные возможности:
-  История операций с временными метками
-  Очистка истории
-  Модульное тестирование
